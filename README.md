# Nertiakit - Laravel Inertia.js SaaS Starter Kit 🚀

Nertiakit is a minimalistic **Laravel + Inertia.js** starter kit designed to accelerate the development of **SaaS applications, admin dashboards, and multi-role web apps**. It includes **authentication, role-based access control (RBAC), a modern UI with ShadCN, and Tailwind CSS**, ensuring a **fast, scalable, and maintainable** foundation.

## ✨ Features

✅ **Authentication with Laravel Breeze** – Login, registration, and password reset  
✅ **Role-Based Access Control (RBAC)** – Spatie Permissions with **Admin & User roles**  
✅ **Inertia.js + React** – Server-driven frontend for a seamless SPA experience  
✅ **ShadCN UI Components** – Beautiful UI with modern styling  
✅ **Tailwind CSS** – Fully responsive, minimalistic, and customizable  
✅ **Toast Notifications** – Real-time success/error alerts with React Toastify  
✅ **Pre-configured Layouts & Dashboards** – Ready-to-use **Admin & User dashboards**
